# ArabicInSanskrit

_Created: 18-01-2015 · Last updated: 11-07-2026_

Arabic (and Perso-Arabic) words occurring in the dictionaries of the
[Cologne Digital Sanskrit Lexicon](https://www.sanskrit-lexicon.uni-koeln.de/).
This repository is a small research workspace for collecting and reviewing
entries in which Arabic-origin terms appear in Sanskrit lexicographic context —
their original Arabic script, transliteration, and the dictionary passages that
cite them.

## How the work is organised

Almost all of the analysis is carried out in the
[issue tracker](https://github.com/sanskrit-lexicon/ArabicInSanskrit/issues)
rather than in committed files. Work is organised per dictionary — one or more
issues per source — recording individual cases (Arabic word, script, gloss, and
the dictionary line that contains it).

As of the last update, all **16** issues are **closed**; there is no open work
item. The recorded cases cover Monier-Williams (MW / MW72), the Petersburg
dictionaries (PW, PWG), and Wilson (WIL), plus general questions such as which
Cologne works contain Arabic strings and how Arabic is anglicized in the
sources. Corrections that resulted from this analysis are applied to the
`csl-orig` source of the relevant dictionary through the standard
[Cologne correction workflow](https://github.com/sanskrit-lexicon/csl-corrections/blob/main/docs/correction-workflow.md),
not committed here.
